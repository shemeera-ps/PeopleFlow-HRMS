# PeopleFlow HRMS – Project Overview

## 1. Introduction

**PeopleFlow HRMS** is a modern Human Resource Management System (HRMS) designed to streamline and automate the day-to-day operations of an organization's Human Resources department.

The application provides a centralized platform for managing employees, departments, attendance, leave requests, payroll, recruitment, performance reviews, and organizational reporting. It is built using a modern technology stack with a Laravel REST API backend and a React frontend to deliver a responsive, secure, and scalable experience.

This project is being developed as a production-style application following software engineering best practices, including modular architecture, RESTful API design, role-based access control, documentation-first development, Git workflows, and clean code principles.

---

# 2. Purpose

The primary objectives of PeopleFlow HRMS are:

- Digitize HR operations.
- Reduce manual administrative work.
- Provide secure access to employee information.
- Improve communication between employees, managers, and HR.
- Enable informed decision-making through reports and dashboards.
- Demonstrate enterprise-level software architecture and development practices.

---

# 3. Project Goals

The project aims to achieve the following:

- Build a scalable HR Management System.
- Follow modular software architecture.
- Develop a secure REST API.
- Implement Role-Based Access Control (RBAC).
- Create a modern and responsive user interface.
- Maintain high code quality and documentation standards.

# 4. Target Users

The system supports multiple user roles.

## Super Administrator

Responsible for configuring the entire application.

Responsibilities include:

- Organization settings
- User management
- System configuration
- Role management
- Permission management

---

## HR Administrator

Responsible for human resource operations.

Responsibilities include:

- Employee onboarding
- Employee records
- Leave approval
- Attendance monitoring
- Payroll management
- Recruitment management

---

## Department Manager

Responsible for managing employees within a department.

Responsibilities include:

- Approve leave requests
- Monitor attendance
- Conduct performance reviews
- View department reports

---

## Employee

Employees can access their own information.

Capabilities include:

- View profile
- Update personal information
- Apply for leave
- View attendance
- Download payslips
- View announcements
