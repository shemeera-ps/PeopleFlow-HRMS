# PeopleFlow HRMS

A modern Human Resource Management System built for scalable organizations.

## Overview

PeopleFlow HRMS is a production-ready web application designed to simplify HR operations and improve employee management. The platform supports employee data, departments, attendance, leave requests, projects, tasks, documents, and internal communications.

The system is built with enterprise-grade best practices in mind, focusing on maintainability, security, and a polished developer experience.

## Key Features

- Employee and department management
- Attendance tracking and leave workflows
- Role-based dashboards for Super Admin, HR Manager, Department Manager, Team Lead, and Employee
- Project and task tracking
- Document management
- Notifications and alerts
- Secure authentication and authorization
- Reporting and analytics-ready architecture

## Target Roles

- **Super Admin**: Full organization control
- **HR Manager**: Employee and HR operations
- **Department Manager**: Manage department employees
- **Team Lead**: Assign work and monitor progress
- **Employee**: View profile, attendance, leaves, tasks, projects
- **Finance** (planned): Payroll and salary management

## Why PeopleFlow HRMS?
